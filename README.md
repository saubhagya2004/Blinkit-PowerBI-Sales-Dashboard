# Blinkit Sales Performance Dashboard (Power BI)

## 📌 Project Overview
This project is an end-to-end Power BI dashboard built to analyze Blinkit sales data and deliver actionable business insights for stakeholders.

The dashboard covers:
- Sales performance
- Product & category analysis
- Payment behavior
- Delivery & operational efficiency

---

## 🛠 Tools & Technologies
- Power BI
- Power Query (ETL)
- DAX
- Excel
- Star Schema Data Modeling

---

## 📊 Dashboard Pages

### 1️⃣ Sales Analysis
- Total Revenue, Orders, AOV
- City-wise revenue performance
- Monthly revenue trends
- Delivered vs Cancelled orders

### 2️⃣ Product Performance Analysis
- Revenue by product category
- Quantity vs revenue comparison
- Top-performing products table

### 3️⃣ Payment & Operations Analysis
- Orders by payment mode (UPI, Card, COD)
- Delivered vs cancelled orders by city
- Delivery success rate

---

## 📈 Key Insights
- Gurgaon and Noida are top revenue-contributing cities
- Dairy and Fruits are the highest revenue-generating categories
- Digital payments (UPI & Card) dominate over COD
- Overall delivery success rate is 80%
